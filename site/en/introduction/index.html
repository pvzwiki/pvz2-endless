INTRODUCTION

A note before we begin.

This is an independent guide to the mechanisms of Plants vs. Zombies 2. Ordinary Endless is its first series; artifacts, accessories, and shared systems extend the exploration. It is not affiliated with or endorsed by EA, PopCap, or the game's operators.

I stopped playing the game years ago.

How this series was made

Drafting was assisted by OpenAI's GPT-6 Astra and Anthropic's Claude Fable 5.1. The explanations draw on resource declarations, ARM64 instruction analysis, isolated checks, and recorded gameplay checks. These are different kinds of evidence; not every described path has been verified in a complete game session.

Errors and omissions are possible. Corrections supported by evidence are welcome, and I am sorry for any confusion caused by mistakes.

What the examples mean

The wave plans use the gameplay settings supplied for this guide: MinWaveCount = 5 and WaveAddInterval = 10. The inspected constructor defaults were 6 and 5 respectively. Health examples use the adopted ten-level Endless gameplay reference; Chapter 04 compares it with the bundled tables and keeps reported attack separate from the native bite calculation. Other numerical inputs use the supplied sample's bundled resources and native constructor defaults unless stated otherwise. The game's effective settings can be supplied by the server. These examples explain the inspected calculation; they are not measurements of the current online game.

The analyzed executable came from an archive labeled version 4.2.2.394. The hash below identifies the exact sample behind the native addresses. Those addresses are unslid virtual addresses within that executable.

Interactive examples use reconstructed random generators and explicit inputs. The integer generator is checked against retained native outputs. The Evolution calculator follows the reference implementation linked on its page and is checked against recorded ordered candidate lists, selections, and shuffle consumption. Its predictions require the displayed starting conditions. Other examples isolate the rules and inputs they explain.

Evidence notes explain the relevant code paths and preserve their native addresses. Code registrations and decompiler output are evidence used in reconstruction, not the game's original source code.

English is the editorial source. The Simplified Chinese version translates the same content, examples, and evidence. Both versions use the same numerical model.
