Reproduce the calculation

Use the same starting conditions

  1. Fully quit and relaunch the game. A level restart alone does not reset the shuffle sequence.
  2. Run exactly the selected number and rank of complete Evolution previews, then enter the selected level directly.
  3. Plant the sources in the numbered order, with the listed effective costs and cell conditions.
  4. Start the waves and activate a rank-1 Evolution artifact once, while the sources remain in place.

Other artifact previews and other consumers of the shared shuffle stream can change the results. The built-in level definitions describe the listed game version; Android and higher-rank activations are outside this calculator’s scope.
